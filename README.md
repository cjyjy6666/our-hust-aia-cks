华中科技大学人工智能与自动化学院C语言课程设计项目

作者为2024级，选题为无人驾驶汽车中控仪表模拟系统

在完成过程中全程使用git进行代码管理,并在完成之后进行开源

**注意**该项目基于早已过时的Borland C++3.1编译器，在虚拟DOS环境中运行，于业界和学界没有意义，仅供后来者参考

***其实于后来者的参考意义也并不大***，我们组二人的最终等级均为B，代码量也并不多。验收我们组的是彭刚老师，他首先更改了"cks"这个文件夹的名字让我们重新建立工程，清点了子界面的个数，然后分别让我们添加一个功能。一个是导航中选择起点和终点时在大地图中显示，另一个则是根据点进导航页面的次数来减小油量、增大行驶里程并在屏幕上显示。

**目录说明**
- include 头文件
- source 源文件
- data 数据文件(文件读写所用到的)
- bmp 贴图

另外还有代代传承的汉字库和鼠标库等
